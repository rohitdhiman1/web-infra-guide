# web-infra-guide

An Astro + Starlight site: a course on web servers, HTTP, HTTPS/TLS and nginx, plus an "APIs on HTTP"
track (A0–A11). Interactive diagrams are React components in `src/components/diagrams/`.

## Rules

- **Formatting:** every module page follows `docs/STYLE.md`. The reference page is
  `src/content/docs/apis/a0-foundations.mdx`. Start new pages with `npm run new-page`; never hand-roll the structure.
- **`source/guide.md` is the original guide.** Don't edit its wording. Its pages
  (`src/content/docs/*.mdx` at the top level) are generated by `npm run split-guide`, so never edit those files directly.
  The API track lives in `src/content/docs/apis/` and is written by hand.
- **No runnable lab projects in this repo.** Snippets only. Full labs live in a separate repo, and this
  repo must not link to it yet.
- **Don't commit or push** unless asked.

## Checks before calling anything done

```bash
npm run build && npm run check-links && npm run check-format
```

Then look at changed pages at desktop and phone width, in light and dark mode.
