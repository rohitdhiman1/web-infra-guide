## Concepts

<span id="concept-6-1"></span>

### <span class="concept-badge">6.1</span> Binary framing (HTTP/2)

Messages are split into typed frames (HEADERS, DATA, SETTINGS and others) instead of text lines.

<span id="concept-6-2"></span>

### <span class="concept-badge">6.2</span> Streams and multiplexing

Many requests share one TCP connection at the same time, each as a numbered stream. This removes HTTP-level head-of-line blocking.

<span id="concept-6-3"></span>

### <span class="concept-badge">6.3</span> HPACK header compression

Repeated headers like cookies are sent as small table references instead of full text.

<span id="concept-6-4"></span>

### <span class="concept-badge">6.4</span> Flow control and prioritization

Per-stream windows stop one big download from starving others.

<span id="concept-6-5"></span>

### <span class="concept-badge">6.5</span> TCP head-of-line blocking remains

One lost packet still stalls every HTTP/2 stream on that connection. This is the problem HTTP/3 solves.

<span id="concept-6-6"></span>

### <span class="concept-badge">6.6</span> QUIC

A transport built on UDP with TLS 1.3 built in. Streams are independent, so a loss affects only its own stream. Connections survive IP changes, like a phone switching from Wi-Fi to mobile.

<span id="concept-6-7"></span>

### <span class="concept-badge">6.7</span> Discovering HTTP/3

Browsers first connect over TCP and learn about HTTP/3 from the `Alt-Svc` header (or an HTTPS DNS record), then switch.

<span id="concept-6-8"></span>

### <span class="concept-badge">6.8</span> Where each is used

Browsers to edge proxies speak HTTP/2 or HTTP/3. Proxies to backends usually still speak HTTP/1.1, because the gains are small on a fast internal network. nginx's `proxy_pass` speaks HTTP/1.x to upstreams; gRPC upstreams use `grpc_pass` over HTTP/2.

## In the sandbox

1. Enable `http2 on;` in nginx (after Part 7). Compare `curl --http1.1 -v` with `curl --http2 -v` and look at the negotiated protocol.
2. Use `h2load` (from the nghttp2 package) to benchmark HTTP/1.1 vs HTTP/2 with many small requests.
3. Enable HTTP/3 in nginx with `listen 443 quic reuseport;`, open UDP 443 in the security group, and add the `Alt-Svc` header. Confirm the protocol in browser DevTools.
4. Use `tc qdisc add dev eth0 root netem loss 2%` on the server to add packet loss. Compare HTTP/2 and HTTP/3 page loads.
